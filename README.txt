Интерактивно помагало по византийско църковно пеене

Изисквания
JDK 17, Apache Maven 3.8

Стартиране
mvn javafx:run

Сертификат
JADE (Java Agent Development Framework) се изтегля от jade.tilab.com. Сайтът е безопасен, но сертификатът му понякога не е в доверения списък на Java по подразбиране. При сглобяване на нова машина може да се появи грешка.
Решението е да се запази като доверен.
